# 참고 UI 반영

- 상단 중앙: STAGE, 현재 턴, 그 아래 결과 카드 5칸.
- 양쪽 캐릭터 위: 체력 수치와 체력바. 플레이어의 보호막/골드 표시.
- 왼쪽 상단: SETTINGS → 소리 켜기/끄기, 닫기.
- 오른쪽: NEXT STAGE. 적 체력이 0이 된 뒤에만 활성화.
- 스핀 중에는 기존 슬롯 창 유지. 종료하면 슬롯 창을 닫고 결과 카드 표시.
- 카드 전체 사용 또는 END TURN → 적 반격 → 플레이어 턴 → 슬롯 창 재표시.
- 적 공격은 기본 10, 스테이지마다 2 증가. 보호막을 먼저 차감하고 나머지를 체력에서 차감.
- 적 체력은 기본 100, 다음 스테이지마다 25 증가. 플레이어 체력/보호막/골드는 유지.
- 패배 시 턴 진행을 중지. 재시작은 Unity 플레이 중지 후 재실행.
- 참고 이미지의 상점 분기는 이번 구현에 포함하지 않았으며 NEXT STAGE는 다음 전투로 진행.

씬 파일을 직접 변경하지 않고 런타임에 BattleHUD를 생성합니다. 기존 Canvas의 Stage와 book은 런타임에 숨깁니다. 생성된 마법 아이콘은 그대로 재사용합니다. CanvasGroup은 사용하지 않습니다.

기존 SpellDrag-Guide의 하단 배치 및 적 AI 미구현 설명은 이 변경으로 대체됩니다. 카드 위치는 SpellResultHand.Initialize의 anchorMin/anchorMax에서 조절합니다.

검증: Unity 6000.5.8f1 어셈블리 참조로 C# 컴파일 확인. 실제 Unity 플레이 화면은 미검증.
확인 순서: 스핀 → 카드 → 방패 사용 → 남은 카드 종료 → 적 반격 시 방패/체력 차감 → 다음 턴 → 적 처치 → NEXT STAGE 활성화 → 다음 스테이지 체력 초기화 및 스핀 재개.
